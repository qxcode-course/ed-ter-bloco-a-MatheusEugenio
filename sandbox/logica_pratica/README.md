# Atividades Incompletas de Lógica de Programação em Go

Complete os códigos abaixo praticando loops, condicionais, recursão, arrays e strings.

## 1. FizzBuzz (draft_fizzbuzz.go)
Imprima de 1 a N: 'Fizz' se %3==0, 'Buzz' %5==0, 'FizzBuzz' ambos, número caso contrário.

**Exemplo entrada:** 15  
**Saída esperada:** 1 2 Fizz 4 Buzz Fizz 7 8 Fizz Buzz 11 Fizz 13 14 FizzBuzz

## 2. Fatorial Recursivo (draft_fatorial.go)
Calcule N! recursivamente.

**Ex:** 5 -> 120

## 3. Soma Excluindo Máx/Mín (draft_soma.go)
Leia N, array de N ints, imprima soma excluindo maior e menor.

**Ex:** 5\n1 2 3 4 5 -> 9

## 4. Palíndromo (draft_palindromo.go)
Verifique se string é palíndromo ignorando maiúsc/minúsc/pontuação. True/False.

**Ex:** "A man, a plan, a canal: Panama" -> true

## 5. Contar Ocorrências (draft_busca.go)
Leia N, array N ints, K; conte quantas vezes K aparece.

**Ex:** 5\n1 3 3 2 3\n3 -> 3

Copie cada arquivo, complete e teste: `go run draft_*.go`
